# Equilateral Triangle

An equilateral triangle is a triangle in which all three sides are equal.

Let each side be `a`.

## Height Formula

h = (√3 / 2)a

where:
- `h` = height
- `a` = side length

## Area Formula

A = (√3 / 4)a²

where:
- `A` = area
- `a` = side length

## Example

If `a = 6 cm`:

- Height = `3√3 cm`
- Area = `9√3 cm²`
