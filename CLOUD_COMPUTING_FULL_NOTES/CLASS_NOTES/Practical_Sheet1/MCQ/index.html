Part 1: AWS VPC (50 Questions)

1. What is a VPC?

A) A public cloud B) Your own private network inside AWS C) A hardware firewall D) A physical storage device
Answer: B Reason: VPC stands for Virtual Private Cloud, which is your logically isolated private network in AWS[cite: 3, 4].

2. Which component allows VPC resources to communicate with the internet?

6. Security Groups are ______.

8. NACLs (Network ACLs) work at which level?

11. A route table consists of ______.
